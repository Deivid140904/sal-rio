# Calculadora de Reajuste Salarial

## Descrição Geral

Este aplicativo foi desenvolvido como parte da disciplina de **Programação Mobile** no curso de **Análise e Desenvolvimento de Sistemas - 3º semestre - FECAP**.

O app permite que o usuário **informe o salário atual de um funcionário** e selecione o **percentual de aumento desejado** (40%, 45% ou 50%). Com base na seleção, o sistema calcula e exibe o **novo salário reajustado** de forma prática e rápida.

## Funcionalidades

- Entrada do salário atual
- Escolha entre os percentuais de aumento: 
  - 40%
  - 45%
  - 50%
- Cálculo automático do novo salário com base na opção selecionada
- Exibição do resultado de forma clara

---

## Desafios e Decisões no Desenvolvimento

Durante o desenvolvimento do aplicativo, enfrentei alguns desafios importantes:

- **Validação de entrada:** adicionei verificações para garantir que o usuário informe um valor válido de salário antes de realizar o cálculo.
- **Seleção de percentual:** utilizei `RadioButtons` agrupados em um `RadioGroup` para assegurar que apenas uma opção de percentual seja escolhida.
- **Clareza no resultado:** formatei a exibição do novo salário para facilitar a compreensão e evitar confusões.
